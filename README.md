### PROJECT 9 - CursorMagic

**Interactive Mouse Effects**

- Advanced custom cursor system with multiple modes
- Dual cursor design (main + follower)
- Particle and trail effects
- Interactive hover zones

**Features:**

- **4 Cursor Modes:**
  - Default: Clean cursor with smooth follower
  - Glow: Radial glow effect with enhanced shadow
  - Particles: Generates colorful particles on movement
  - Rainbow: Animated rainbow color cycling

- **Interactive Zones:**
  - Hover Grow: Cursor enlarges on hover
  - Spin It: Rotating cursor animation
  - Blend Mode: Mix-blend-mode difference effect
  - Trail Effect: Colorful dot trail following mouse

- **Advanced Features:**
  - Smooth easing animation for follower cursor
  - Random particle generation with physics
  - Dynamic trail creation system
  - Mode switcher with visual feedback
  - Hover detection on clickable elements
  - Cursor hide/show on window boundaries

**Technologies:**

- RequestAnimationFrame for smooth animations
- CSS animations and transforms
- Mix-blend-modes for visual effects
- Glassmorphism and backdrop filters
- Mobile-responsive (shows default cursor on touch devices)

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional but recommended)

### Installation

1. **Clone or Download** the repository

   ```bash
   git clone <your-repository-url>
   cd "JS PROJECTS"
   ```

2. **Open with Live Server**
   - Using VS Code: Install "Live Server" extension
   - Right-click on `index.html` → "Open with Live Server"

   OR

3. **Open Directly**
   - Navigate to the project folder
   - Double-click `index.html` to open in your browser
   - Navigate to individual projects from the main page
